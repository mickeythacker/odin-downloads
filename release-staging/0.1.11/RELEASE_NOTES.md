# Project Odin 0.1.11

This release repairs packaged Windows notifications and completes the recovery
path for installed Odin builds.

The frozen Windows application now includes the PowerShell notification helper
required by market, workflow, Neo, persistence, and health notifications.

Project Odin 0.1.10 already moved the packaged collector and watchdog onto the
installed ODIN.exe. Version 0.1.11 fixes the remaining missing notification asset.

The in-app Help & User Guide and Mímisbrunnr / The Well remain included.
